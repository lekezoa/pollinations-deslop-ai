# ✍️ DeSlop AI

[![Made with pollinations.ai](https://raw.githubusercontent.com/pollinations/pollinations/main/packages/ui/src/brand/badge-made-with.svg)](https://pollinations.ai/?ref=badge)

**DeSlop AI** is an intelligent writing and prose-refining tool built for **POLLEN-QUEST #19180** that detects artificial "LLM voice" tells and rewrites text into authentic, direct human prose using **Pollinations.ai** models (`openai-large`, `mistral`).

## 🌐 Live Web App
- **Live Demo:** [https://lekezoa.github.io/pollinations-deslop-ai/](https://lekezoa.github.io/pollinations-deslop-ai/)

## 🚀 Features
- **Real-Time Slop Index (0–100%):** Scans for stereotypical machine-written phrases ("delve into", "tapestry", "pivotal role", "beacon of hope", "in summary").
- **Voice Style Selectors:** Rewrite in Direct & Concise, Casual Conversational, Journalistic, or Academic style.
- **De-Slopping Engine:** Uses Pollinations LLM with custom humanization prompts to strip buzzwords, throat-clearing, and robotic cadence.
- **Bring Your Own Pollen (BYOP):** Integrated API key support for users to power rewrites with their own Pollen balance.

## 🛠️ Built With
- **Pollinations.ai API:** `https://gen.pollinations.ai/v1/chat/completions`
